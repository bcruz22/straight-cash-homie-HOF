# Straight Cash Homie Hall of Fame

League history site for the Straight Cash Homie keeper league: champions, record book, rivalries, franchises, keepers, trades.

- `docs/` is the website (published with GitHub Pages).
- `scripts/` pull the league's public Sleeper data and rebuild `docs/data/`.
- `tracker.json` holds the commissioner's keeper corrections and manager names.
- `.github/workflows/refresh.yml` reruns the scripts every Tuesday during the season. Run it any time from the Actions tab ("Weekly refresh", Run workflow).
